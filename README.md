# AUGMENT BOOK · 증바람 연구소

무작위 총력전: 아수라장 증강을 탐색하는 한국어 정적 웹사이트입니다. HTML/CSS/JavaScript로 작성되어 별도 설치나 빌드가 필요하지 않습니다.

- 기능별 탭: 연구소 홈, 증강 도감, 챔피언 추천, 조합 실험실, 데이터 노트
- 전체 챔피언 173명: 초상화, 이름 검색, 역할 필터, 조합 선택
- 208개 증강: 효과 설명, 실버·골드·프리즘 등급, 검색, 필터, 즐겨찾기
- 140명 통계 기반 추천: 승률·선택률 반영 비중과 최소 선택률 조절
- 1,400개 실제 증강 조합 통계와 임의 조합 조회
- 선택률·승률 산점도, 등급별 시각 자료, 스킬 가속 실험

같은 패치의 통계를 확보하지 못한 33명은 통계 미확보로 표시합니다. 승률이나 선택률을 만들어 넣지 않습니다.

## 실행과 검사

이 디렉터리를 정적 웹 서버로 제공하면 됩니다. 예: `python3 -m http.server 8000` 실행 후 `http://localhost:8000`을 여세요. JSON을 불러오므로 HTML 파일을 직접 여는 방식보다 웹 서버 사용을 권장합니다.

Node.js가 설치되어 있으면 다음과 같이 검사할 수 있습니다.

```sh
node --check app.js
node check.mjs
```

검사 범위: 전체 챔피언 초상화 URL과 선택 목록, 증강 설명·등급·이름 연결, 524개 화면 템플릿, 추천 계산, 필터, 조합의 확인·미확인·중복 상태입니다. 브라우저 화면 검증은 원본 작업의 미리보기 환경 문제로 완료되지 않았습니다.

## GitHub Pages

기존 `.github/workflows/pages.yml`을 사용합니다. `master` 브랜치에 변경 사항을 반영하면 저장소 루트를 자동으로 배포합니다. 저장소 **Settings → Pages → Source**가 **GitHub Actions**로 설정되어 있어야 합니다. 모든 정적 파일 경로는 상대 경로입니다.

## 데이터와 추천 기준

- 챔피언 정보·초상화: Riot Data Dragon 16.20.1, 전체 173명. 2026-10-21에 16.21.1의 챔피언 ID 목록과 비교했으며 추가된 ID는 없었습니다.
- 경기 통계: 2026-10-20~21에 확인한 ARAMKit 클라이언트 패치 16.20 / 공개 패치 26.20의 공개 스냅샷입니다. 140명 각각 상위 증강 12개와 조합 10개를 담았습니다. 각 챔피언 데이터에 출처 URL과 확인일이 포함됩니다. 이전 패치 자료는 제외했습니다.
- 증강 효과: ARAMMayhem 공개 자료를 한국어로 요약하고 ARAMKit·ARAMGG·Riot 패치 노트로 보완했습니다. 각 증강에 개별 출처가 있습니다. ARAMMayhem 공개 데이터의 라이선스는 CC BY 4.0입니다.
- 기본 추천 점수: 후보 안에서 정규화한 승률 70% + 정규화한 `log(1 + 선택률)` 30%입니다. 비중과 필터를 바꾸면 다시 계산합니다. 점수는 상대 순위이며 예상 승률이 아닙니다.

지역별 원본 경기, 개별 표본 수, 신뢰구간은 제공하지 않습니다. 실시간 API나 자동 갱신은 없으며, 증강 도감의 전체 선택률은 챔피언별 추천 통계와 섞지 않습니다. 상세한 한계와 출처는 사이트의 데이터 노트에서 확인할 수 있습니다.

## 버전과 시각 자료

배포된 [증바람 연구소](https://augment-book-kr.keumss2015.chatgpt.site)의 소스 커밋 `e71bd1254931670e41804a35a40c42f0440c504d`와 동일한 화면·추천 로직·통계를 제공합니다. 원본 `dist/`의 파일을 이 저장소 루트에 배치하고 검사 파일의 기준 경로를 조정했습니다. 챔피언 초상화는 기존 저장소 방식대로 같은 버전의 Riot 공식 CDN에서 불러옵니다. 배너와 아이콘은 로컬 파일로 포함됩니다.
