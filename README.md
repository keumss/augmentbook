# AugmentBook · 증바람 증강 연구소

칼바람 아수라장 증강 가이드입니다. HTML/CSS/JavaScript로 작성된 정적 웹사이트이며 별도의 빌드가 필요하지 않습니다.

- 핵심 증강 26선: 효과 설명, 희귀도 등급, 활용법과 주의점
- 챔피언 173명: 20명 개별 시너지 해설, 나머지 역할군 기반 추천
- 증강 검색, 등급/스타일 필터, 즐겨찾기, 최대 4개 조합 저장
- 스킬 가속/치명타 원리 실험

## GitHub Pages

1. 이 디렉터리 내용을 `keumss/augmentbook` 저장소의 `master` 브랜치에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. **Actions → Deploy GitHub Pages → Run workflow**를 실행합니다. 이후 master 브랜치에 push하면 자동 배포됩니다.

모든 로컬 에셋 경로는 상대 경로라 프로젝트 Pages 하위 경로에서도 사용할 수 있습니다.
